# 📊 Sales Dashboard Project (End-to-End Data Analytics Learning)

---

# 🚀 Project Overview

This project is a **complete end-to-end data analytics application** built using:

* **Python**
* **Pandas**
* **Matplotlib**
* **Plotly**
* **Streamlit**

It demonstrates the full workflow of a data analyst:

👉 Data → Cleaning → Analysis → Visualization → Dashboard → User Interaction

---

# 🎯 Objectives

* Understand **real-world data handling**
* Apply **data visualization techniques**
* Build an **interactive dashboard**
* Implement **data editing & persistence**
* Follow **industry-level project structure**

## 📈 4. Matplotlib (Core Visualization)

* `plt.figure()` vs `fig, ax`
* Line plots
* Bar charts
* Scatter plots
* Histograms

### Advanced Concepts:

* `annotate()` → highlight insights
* Axis limits (`set_xlim`, `set_ylim`)
* Ticks (`set_xticks`, `set_yticks`)
* Twin axes (`twinx()`)
* Styling (`ggplot`, colors, markers)
* Exporting (`dpi=300`, PNG, PDF, SVG)

---

## 🎨 5. Data Visualization Thinking

Choosing the right chart:

* **Bar chart** → category comparison
* **Line chart** → trends over time
* **Scatter plot** → relationships
* **Histogram** → distribution

# ⚙️ Installation & Setup

## 1. Clone Repository

```bash
git clone <your-repo-link>
cd sales-dashboard-project
```

---

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3. Run Application

```bash
streamlit run app/app.py
```
